راهنمای نصب نود Monefa (XMF)

نصب نود بلاکچین Monefa روی Ubuntu — از صفر تا ماینینگ CPU زنده

Ubuntu 20.04+ ۲ هسته CPU / 2GB RAM CryptoNight-Lite-Fa

⚡ نصب سریع — فقط یک خط!

اگر فایل easy-install.sh را از بسته دانلودی دارید، همه مراحل زیر (پیش‌نیازها + نود + وب + سرویس دائمی + فایروال) به‌صورت خودکار انجام می‌شود:

bash easy-install.sh

یا به‌صورت کاملاً خودکار از مخزن:

wget -O easy-install.sh https://YOUR-SERVER/easy-install.sh && bash easy-install.sh

مراحل دستی زیر برای کسانی است که می‌خواهند گام‌به‌گام نصب کنند.

۱

پیش‌نیازها

ابزارهای پایه و زمان اجرای Bun را نصب کنید:

sudo apt update && sudo apt upgrade -y
sudo apt install -y curl git build-essential unzip

# نصب Bun (زمان اجرای پرسرعت جاوااسکریپت)
curl -fsSL https://bun.sh/install | bash
source ~/.bashrc
bun --version
۲

دریافت و آماده‌سازی نود

بسته سورس را در مسیر /opt/monerofa قرار دهید:

sudo mkdir -p /opt/monerofa
sudo unzip monefa-network-v1.0-source.zip -d /opt/monerofa
# یا: git clone <آدرس-مخزن-شما> /opt/monerofa
sudo chown -R $USER:$USER /opt/monerofa
cd /opt/monerofa
۳

نصب وابستگی‌ها و دیتابیس

cd /opt/monerofa
bun install
bun run db:push

دیتابیس SQLite در مسیر db/custom.db ساخته می‌شود — نیازی به دیتابیس خارجی نیست.

۴

کلیدهای رمزنگاری

فایل .env با کلیدهای تصادفی بسازید:

cat > /opt/monerofa/.env << 'ENV'
DATABASE_URL=file:/opt/monerofa/db/custom.db
WALLET_SECRET=<یک-رشته-تصادفی-بلند>
SESSION_SECRET=<یک-رشته-تصادفی-دیگر>
ENV

# تولید کلید تصادفی:
openssl rand -hex 32

⚠️ WALLET_SECRET برای رمزگشایی کلیدهای کیف پول‌هاست — اگر گم شود، کیف پول‌ها قابل بازیابی نیستند. پشتیبان بگیرید!

۵

اجرای نود

اجرای مستقیم برای تست:

cd /opt/monerofa/mini-services/monerofa-node
bun src/node.ts
پورتکاربرد
3030WebSocket — P2P + ماینینگ راه‌دور + پخش زنده
3031HTTP API داخلی (فقط localhost)
۶

سرویس systemd — اجرای دائمی

برای اجرای خودکار پس از ری‌استارت سرور:

sudo tee /etc/systemd/system/monerofa-node.service > /dev/null << EOF
[Unit]
Description=Monefa Blockchain Node
After=network.target

[Service]
Type=simple
User=$USER
WorkingDirectory=/opt/monerofa/mini-services/monerofa-node
EnvironmentFile=/opt/monerofa/.env
ExecStart=$(which bun) src/node.ts
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
EOF

sudo systemctl daemon-reload
sudo systemctl enable --now monerofa-node
sudo systemctl status monerofa-node

لاگ زنده: journalctl -u monerofa-node -f

۷

ماینینگ CPU

روش ۱ — اتصال به استخر (پیشنهادی): پاداش به‌صورت PPLNS تقسیم و خودکار پرداخت می‌شود:

cd /opt/monerofa/mini-services/monerofa-node
bun src/miner-cli.ts \
  --url ws://SERVER-IP:3030 \
  --address 4xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx \
  --worker rig1 \
  --threads 8

روش ۲ — انفرادی (solo): پاداش بلاک مستقیم به آدرس شما:

bun src/miner-cli.ts --solo \
  --url ws://SERVER-IP:3030 \
  --address 4xxx... --threads 8

ماینر راه‌دور به دیتابیس نیاز ندارد — فقط WebSocket به نود کافی است. روی هر سرور دیگر هم می‌توانید همین دستور را اجرا کنید.

۸

اتصال نودهای دیگر (P2P)

روی سرور دوم همین نصب را انجام دهید و همتا را معرفی کنید:

# هنگام اجرای نود:
PEERS=ws://SERVER1-IP:3030 bun src/node.ts

# یا بدون ری‌استارت — از پنل مدیریت → همتاهای P2P → ws://SERVER1-IP:3030

نودها به‌طور خودکار همگام می‌شوند و بلاک‌ها و تراکنش‌ها بین همتاها منتشر می‌شود.

۹

امنیت و فایروال

  • باز کردن فقط پورت‌های لازم: sudo ufw allow 22,3000,3030/tcp
  • پورت 3031 (HTTP API) را فقط برای localhost نگه دارید.
  • اگر حساب مدیریتی پیش‌فرض دارید، گذرواژه‌اش را فوراً عوض کنید.
  • پشتیبان‌گیری دوره‌ای: cp db/custom.db backup/
  • عبارت بازیابی (سید) کیف پول‌ها را روی کاغذ و خارج از سرور نگه دارید.
